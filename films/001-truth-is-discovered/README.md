an irreversible DAG of frozen results, and the open frontier.

[trureturing](https://github.com/the-omega-institute/trureturing) 项目：
真理是被发现的；Lean 内核是唯一的判官；验证过的结果冻结进一张只增不减的真理 DAG；工作只发生在开放前沿。

## How it was made · 制作方式

Everything is generated by code — no stock footage, no image models.

- **Picture**: `engine.js` draws each frame deterministically on a 1920×1080 Canvas (`renderAt(t)`); headless Chromium (Playwright) captures frames and pipes them to x264.
- **Narration**: [Kokoro-82M](https://github.com/thewh1teagle/kokoro-onnx) ONNX, voice `af_heart`, synthesized locally line by line (`tts.py`) → `timeline.json`, which drives every animation cue and subtitle.
- **Score & SFX**: synthesized in numpy/scipy (`music.py`): D-minor pads, bass, arpeggio, drums, risers, impacts, glitches, heartbeat; `mix.py` ducks the music ~12 dB under speech.
- **Fonts**: Orbitron, JetBrains Mono, Rajdhani, Noto Sans SC (SIL OFL) via `@fontsource` npm packages.

### Rebuild · 复现

Requires Python 3.11+, Node 22 with `playwright` and a Chromium, and `curl`/`npm`.

```sh
./setup.sh            # Python deps, Kokoro model, fonts (not committed)
python3 tts.py        # narration.wav + timeline.json
python3 music.py      # score + SFX (music_bed.wav)
python3 mix.py        # mix_voice.wav / mix_music.wav
./render_all.sh       # 12,433 frames -> seg_*.mp4  (≈20 min on 4 cores)
./mux.sh              # master files (CRF 17)
./hd.sh               # 1080p two-pass versions under 100 MB
```

Edit `script.json` to change the narration; rerun `tts.py` and every scene re-times itself.
改 `script.json` 即可改旁白，重跑 `tts.py` 后所有场景自动重新对时。

## Scope · 边界

The film is an explanation, not a proof. Its claims follow the project’s own statements:
trureturing has **not** solved the Riemann hypothesis; its spacetime volumes are models of
observation, not physical derivations; the information-escape judge is still under
construction. The Lean source in trureturing remains the only authority.
本片是讲解而非证明；以上边界均按项目自身表述。
