This film continues the versioned AURIC volumes and runs 7:21. It covers two volumes of
trureturing at subject commit `fd77822991`:
- `AURIC_NORMALIZATION_UNITS_OBSERVER_ORIGINS_AND_QUADRATIC_INVARIANTS_V41.md`, §1–§11;

Version forty-one asks what the null mode, normalisation and the three-axis square sum each carry: the unit is the sum
of all events, three numbers describe a whole state space only in two cases, an observer's reference state needs a
centre and a metric, and masses and coherences fill exact quadratic budgets. Version forty-two reads the joint mode
F[13] as a relation between two ends: it narrows a fibre, it can be generated by interior structure or by two
reflections, and recursion keeps exactly the relations that change an allowed future.

    the real functions. The events are e_N = 1 − ξ − η − ζ + ξη, e₁ = ξ − ξη, e₂ = ζ, e₃ = η − ξη, e₁₃ = ξη; they

  - Normalisation is ω(1) = Tr ρ = 1, a condition on the unit; p_N is part of the state.
  - (s, X, Y, Z, κ) are complete coordinates with w = (s − X − Y − Z + κ, X − κ, Z, Y − κ, κ). At s = 1 the fibre
    over fixed axes is max(0, X + Y + Z − 1) ≤ κ ≤ min(X, Y), and X + Y + Z = 1 − p_N + p₁₃ (Theorem 2.4).
    ½δ_N + ½δ₁₃ and ½δ₁ + ½δ₃ both read (½, ½, 0) with κ = ½ and 0.
- **Three numbers (V41 §3).**
  - For B = ⊕ M_dα(ℂ) with n = Σ dα², three readouts are complete on all states exactly when
    span{I, E₁, E₂, E₃} = B_sa; three complete readouts exist exactly when n ≤ 4; a complete state space of exactly
    three dimensions is M₂(ℂ) or ℂ⁴ (Theorem 3.2). The table of state dimensions 1, 3, 3, 4, 24, 15 is shown.
  - Two classical signs: p_st = (1 + sa + tb + st c)/4, the means fill the tetrahedron with vertices (s, t, st), and
    a² + b² + c² = 4Σp_st² − 1 ∈ [0, 3] (Proposition 3.3). The qubit's extreme points are the whole unit sphere. For two
    qubits 4 Tr ρ_AB² − 1 = |a|² + |b|² + ‖T‖_F².
- **Observer origin (V41 §4–§5).**
  - For positive M with s = p + q and r_hom = (2 Re c, −2 Im c, p − q): M ≥ 0 ⇔ s ≥ |r_hom| and
    s² − |r_hom|² = 4 det M; on the slice s = 1, |r|² = 2 Tr ρ² − 1 = 1 − 4 det ρ (Theorem 4.2). This scene's first
    line is the standard Bloch background, badged classical.
  - For readouts E_i = a_i I + b_i · σ with H = BBᵀ: |r|² = (m − a)ᵀH⁻¹(m − a); with an observer origin ρ_O,
    |r|² = (d + Br_O)ᵀH⁻¹(d + Br_O) and dᵀH⁻¹d = |r − r_O|² = 2 Tr(ρ − ρ_O)² (Theorem 5.2). With reference |0⟩⟨0|
    the state I/2 has relative coordinates (0, 0, −1), relative square sum 1, purity ½. I/2 is the only unitarily
    invariant state, and one reference fixes an axis but not the transverse phase (Proposition 5.3).
- **Exact budgets (V41 §6–§8).**
  - For Ψ = |0⟩ ⊗ a + |1⟩ ⊗ b with p + q = 1: P² + V² + G² = 1 and |r|² + G² = 1, with P = |p − q|, V = 2|c|,
    G = 2√(pq − |c|²); G = 0 exactly for dependent records (Theorem 6.1). Also Σ Var σᵢ = 3 − |r|² = 2 + G² and
    D² + V² = 1, D² = P² + G² (Proposition 6.2).
  - Σ p_s² = 1/5 + δqᵀH₅δq with δq = (X, Y, Z, κ) − (2/5, 2/5, 1/5, 1/5) and H₅ = AᵀA > 0; for a quantum state
    Tr ρ² adds 2Σ_s<t |ρ_st|² (Theorem 7.2). p_A = (½, 0, 0, 0, ½) and p_B = (¼, ¼, 0, ¼, ¼) share the axes
    (½, ½, 0) with purities ½ and ¼. On block algebras Tr ρ̄² = Σ t_s² Tr ρ_s² (Theorem 8.1).
- **Renormalisation (V41 §9–§10).**
  - ‖M/s − N/t‖₁ ≤ (δ + |s − t|)/max(s, t) ≤ 2δ/max(s, t), attained by M = s|0⟩⟨0|, N = M + δ|1⟩⟨1|; η|0⟩⟨0| and
    η|1⟩⟨1| show there is no global Lipschitz constant (Theorem 9.2).
  - 1 − |r_n|² = (1 − |r₀|²) Π|det K_j|²/(Π t_j)², with total mass Π t_j (Theorem 9.3).
  - K = diag(1, ε) keeps pure states pure, yet the outputs of |±⟩ overlap (1 − ε²)/(1 + ε²) (Proposition 9.4). A CPTP
    map that preserves the Bloch radius of every state is unitary; a transpose would keep radii but has eigenvalue −½

- **Relation fibre (V42 §1–§3).**
